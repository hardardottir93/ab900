Purview carries the most weight and has the most traps. Always ask yourself whether the question is about finding, protecting, stopping, keeping or investigating data.

Copilot

  • The golden rule: Copilot only sees what the user is allowed to see. Graph retrieves the context (files, mail, meetings, chats).
  • Prompts and responses are not used to train models and get the same protection as email and files.
  • Copilot Chat (free, web-grounded, standalone) vs Microsoft 365 Copilot (licensed, Graph data, built into Word/Excel/Outlook/Teams).
  • "Copilot isn't showing in Word": Service health first → licence → Microsoft 365 Apps for enterprise (File → Account → Update now).
  • Copilot in Teams needs meeting transcription.
  • The Word, Excel and PowerPoint agents disappear if the Anthropic AI models connection is turned off in the M365 admin center.
  • Enabled Users = licensed · Active Users = actually used it. Reports lag 24–48 hours.
  • Viva Insights Copilot Analytics = Copilot Dashboard + Advanced Insights Analyst Workbench.
  • Researcher = multi-step research with citations (unstructured data) · Analyst = tabular data, no DAX.
  • Copilot Control System → Data access controls which users and groups can use agents.
  • Defender for Office 365 = phishing, malicious links and malware in email and files.
  • Copilot Control System: AI security controls (monitor, detect, respond) · Compliance & privacy · Management · Measurement & reporting.
  • 6 Responsible AI principles: Fairness · Reliability & safety · Privacy & security · Inclusiveness · Transparency · Accountability.

Pay-as-you-go

  • Two steps, both required: 1) create a billing policy, 2) connect it to the service on the Pay-as-you-go services tab. Off by default.
  • Scope: all users or one group — not individual users.
  • Alerts at 80% and 100% · budget resets monthly, quarterly or yearly.
  • M365 admin center = overview · Azure Cost Management = group by UPN, forecasts, CSV / Power BI export.
  • Licence = built-in Copilot features · PAYG = usage charges for data retrieval and APIs. Monthly licences = security risk (overlicensing); PAYG = financial risk.

  • Declarative = M365 data + built-in orchestration · Custom engine = own orchestration, external systems, own models.
  • Template trap: a template in Configure resets everything you did in Describe.
  • The ready-made site agent is locked. A custom SharePoint agent is a .agent file in Site assets → Copilots.
  • Updated SharePoint agent with restricted files → reshare it.

Vistað í þessum vafra

Niðurstöðurnar þínar sjást bara hjá þér. Aðrir sem nota síðuna sjá ekki þína framvindu og þú ekki þeirra.

Geyma framvinduna

Framvindan er aðeins geymd í þessum vafra, á þessu tæki. Hún tapast ef vafrinn er hreinsaður eða ef þú skiptir um tæki. Sæktu hana því reglulega í skrá og hlaðaðu henni inn aftur hér þegar þarf.

Hér er ekki hægt að sækja skrá beint. Afritaðu textann og vistaðu hann, eða límdu inn texta úr eldra afriti og smelltu á „Hlaða inn texta“.

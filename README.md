# AB-900 æfingasvæði

Æfingavefur fyrir prófið **Microsoft 365 Certified: Copilot and Agent Administration Fundamentals (AB-900)**.

- **Próf**: spurningar úr Microsoft-æfingaprófinu og próf úr YouTube-fyrirlestrunum, með einkunn eftir sviðum
- **Upprifjun dagsins**: endurtekning með millibili á spurningum sem var svarað vitlaust (1, 3 og 7 dagar)
- **Lykilatriði**: samantekt á því mikilvægasta (á ensku)
- **Fyrirlestrar**: enskar glósur úr 39 fyrirlestrum með hlekk á hvert myndband
- **Leit** í glósum, lykilatriðum og spurningum
- Ljóst og dökkt útlit

Hægt er að setja síðuna upp sem app á heimaskjánum (Chrome: „Install app“ / Safari: Deila → „Add to Home Screen“). Hún virkar þá líka án nettengingar.

Framvindan vistast í vafranum. Hægt er að sækja hana í skrá og hlaða henni inn aftur undir „Framvindan mín“.

## Heimildir

- Fyrirlestrarnir: [Microsoft AB-900: Copilot and Agent Administration Masterclass](https://www.youtube.com/playlist?list=PLeAdpmiY-mCf-1ysvpuGMbtgQsOKV5ESW) á YouTube. Glósurnar eru samantekt á efni fyrirlestranna.
- Microsoft-spurningarnar koma úr [ókeypis æfingaprófi Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/copilot-and-agent-administration-fundamentals/practice/assessment?assessment-type=practice&assessmentId=428463062) og eru í eigu Microsoft.

Þetta er óopinbert námsefni og tengist hvorki Microsoft né höfundi fyrirlestranna.
